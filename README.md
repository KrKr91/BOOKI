# Booki - Trouvez l'hébergement de vos rêves

## Description du projet
Ce projet a été réalisé dans le cadre de la formation **Développeur Web chez OpenClassrooms** (Projet 2).
L'objectif était d'intégrer l'interface du site de l'agence de voyage "Booki", en transformant une maquette Figma en un site web entièrement fonctionnel et responsive.

##  Objectifs d'apprentissage atteints
* Intégration d'une maquette au format Desktop, Tablette et Mobile.
* Implémentation d'une interface responsive avec une approche **Mobile First**.
* Utilisation massive de **CSS Flexbox** pour la mise en page.
* Écriture d'un code **HTML5 sémantique** pour un meilleur référencement (SEO) et une meilleure accessibilité.
* Code validé sans erreurs par le validateur W3C (HTML et CSS).

## Technologies et Outils utilisés
* **HTML5** (Structure et sémantique)
* **CSS3** (Style, Flexbox, Media Queries)
* **FontAwesome** (Icônes)
* **Google Fonts** (Police d'écriture *Raleway*)
* **Figma** (Analyse de la maquette et extraction des assets)
* **Git & GitHub** (Versionning)
